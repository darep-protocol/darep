# Security policy

## Scope and private reporting

This policy covers the DAREP specification, test vectors, and Node and Python reference implementations in this repository.

Report vulnerabilities privately through [GitHub Private Vulnerability Reporting](https://github.com/darep-protocol/darep/security/advisories/new), or email **security@darep.org**. Please do not open a public issue for an undisclosed vulnerability.

Include the affected files and version or commit, a description of the vulnerability and its impact, reproduction steps or a minimal proof of concept, and any suggested fix. Include contact details for follow-up and your disclosure preferences. Use test data and omit live credentials, private keys and personal data.

## Response and coordinated disclosure

We aim to acknowledge reports within **5 business days**. The editor will coordinate investigation, remediation and disclosure with the reporter and affected implementers, sharing progress privately.

The default coordinated disclosure window is **90 days from receipt of the report**. We will agree on a publication date with the reporter, normally after a fix is available. The date may be shortened for active exploitation or extended by agreement when remediation needs more time. Public disclosure will describe the impact, affected versions and available mitigation, with reporter credit if requested. Embargoed security handling is an exception to the open change process in [GOVERNANCE.md](GOVERNANCE.md).
